# QSAR Regression Model

## Overview

This project demonstrates a basic QSAR (Quantitative Structure–Activity Relationship) workflow using molecular descriptors and machine learning.

The model predicts LogP values from molecular descriptors generated using RDKit.

## Features Used

* Molecular Weight (MW)
* Topological Polar Surface Area (TPSA)
* Hydrogen Bond Donors (HBD)
* Hydrogen Bond Acceptors (HBA)

## Machine Learning Model

* Random Forest Regressor
* Train/Test Split
* R² Score Evaluation

## Workflow

Molecular Dataset → Descriptor Selection → Train/Test Split → Random Forest Regression → LogP Prediction → Model Evaluation

## Technologies Used

* Python
* Pandas
* RDKit
* Scikit-learn
* Matplotlib

## Learning Outcomes

* Feature selection
* Target variable selection
* Train/test split
* Regression modeling
* Model evaluation using R² score

This project serves as an introduction to QSAR modeling and machine learning in cheminformatics.
